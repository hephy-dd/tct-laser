# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

## [0.4.0] - 2026-08-28

### Added

- Presets for raster scan options (#9).
- Relative and absolute movement actions to stage control.

### Changed

- Raster plot axes show relative offsets to starting point.
- Renamed raster scan offset inputs.

## [0.3.0] - 2026-08-03

### Added

- Raster Scan XZ and YZ profile plots (#8).
- Raster Scan configurable output options (Plots, CSV) (#8).

## [0.2.0] - 2026-07-30

### Added

- Stage positions management with absolute moves (#7).

### Changed

- Reorganized operation inputs in group boxes for improved usability (#5).

### Fixed

- Failing to display non-square raster scans (#6).

## [0.1.1] - 2026-07-27

### Added

- This CHANGELOG file.

### Fixed

- Configure scope waveform format before running operations (#2).
- Using modern Python typing syntax and resolved all Ruff linting issues (#3).

## [0.1.0] - 2026-07-24

### Added

- Z scan opertion.
